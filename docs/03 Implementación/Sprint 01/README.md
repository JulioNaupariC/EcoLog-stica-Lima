# Sprint 1 — Base Operativa

Esta carpeta reúne los entregables de la rúbrica del Sprint 1 (11/09/2026–02/10/2026),
en la versión entregada el 02/10/2026 (commit `58c3d9c`, rama `sprint-1`). Se
recuperaron en `main` sin cambios de contenido (ECL-92): solo se ajustaron las rutas
de sus enlaces a la nueva ubicación. Los enlaces a documentos que cambiaron de versión
después del Sprint 1 apuntan a la versión de la rama `sprint-1`, que es la que se citó.

El Sprint 1 no tiene documentación técnica propia en esta carpeta: la instalación y
las pruebas de esa versión están en los README de
[backend](https://github.com/JulioNaupariC/EcoLog-stica-Lima/blob/sprint-1/backend/README.md)
y [frontend](https://github.com/JulioNaupariC/EcoLog-stica-Lima/blob/sprint-1/frontend/README.md)
de la rama `sprint-1`.
